Programlamaya Giriş – İnteraktif Masallar

Proje Hakkında

Bu proje, Programlamaya Giriş dersi kapsamında hazırlanmış, HTML, CSS ve JavaScript kullanılarak geliştirilmiş interaktif bir masal web sayfasıdır.

Kullanıcılar web sayfası üzerinden masalları okuyabilir ve sunulan etkileşimli özellikleri kullanabilir.

Proje Nasıl Açılır?

Proje dosyalarını bilgisayarınıza indirin.

index.html dosyasını bulun.

Dosyaya çift tıklayarak Safari, Chrome veya başka bir web tarayıcısında açın.

Sayfa internet bağlantısı olmadan da çalışabilir.
